# OpenCooler (Forge 1.12.2-14.23.5.2860)

Сборка через ForgeGradle 5 + FancyGradle (для Forge 2851-2860), Gradle 7.5.1, JDK 8.
1. Положите jar OpenComputers в libs/
2. gradlew --stop
3. gradlew build
Jar: build/libs/OpenCooler-1.12.2-1.0.0.jar
Использование: термопаста/тряпка в одной руке, ЦП в другой, ПКМ.
Lua: lua/temp_monitor.lua
